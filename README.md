# ☁️ WeCloud – Cloud Solutions Portfolio Website

A modern, responsive, and high-performance landing page and portfolio website built for a fictional cloud infrastructure and DevOps consulting company, **WeCloud**.

Designed entirely with **vanilla web technologies**, this project emphasizes clean design, smooth animations, accessibility, and zero external framework bloat.

---

## ✨ Features

- **Modern UI/UX Design:** Built with a professional tech-focused color palette (`--ink`, `--azure`, `--amber`), CSS variables, glassmorphism effects, and smooth typography (`Manrope`).
- **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile devices with a custom mobile navigation toggle.
- **Interactive Environment Dashboard:** Simulated live system monitor in the hero section with animated dynamic activity bars.
- **Animated Stat Counters:** JavaScript-powered count-up animations triggered via the `IntersectionObserver` API as the user scrolls into view.
- **Dynamic Content Injection:** Services, success stories, team bios, and partner logos are rendered dynamically using clean JavaScript template literals to keep the HTML markup lean.
- **Client-Side Form Validation:** Interactive contact form with real-time field validation for names, email formatting, and message lengths, paired with an accessible success feedback state.
- **Accessibility & Performance Ready:** Includes high-contrast focus states, ARIA attributes, and support for `prefers-reduced-motion`.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic layout with structured landmark tags (`<header>`, `<main>`, `<section>`, `<footer>`).
- **CSS3:** Modern layout systems (CSS Grid, Flexbox), custom CSS properties (variables), media queries, and fluid typography via `clamp()`.
- **Vanilla JavaScript (ES6+):** DOM manipulation, event listeners, canvas/SVG rendering logic, `IntersectionObserver`, and form validation logic.

---

## 🚀 Getting Started

Since this is a lightweight, single-file static project, you don't need any complex build steps, package managers, or Node.js environments to run it.

### Prerequisites

You only need a modern web browser (Google Chrome, Firefox, Safari, Microsoft Edge).
